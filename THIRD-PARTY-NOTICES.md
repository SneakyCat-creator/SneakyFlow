# Third-party components

SneakyFlow uses these unmodified components:

- MonoTorrent 3.0.3-alpha.unstable.rev0049 — MIT — https://github.com/alanmcgovern/monotorrent
- Mono.Nat 3.0.0 — MIT — https://github.com/alanmcgovern/Mono.Nat
- ReusableTasks 4.0.0 — MIT — https://github.com/alanmcgovern/ReusableTasks
- .NET 10 / Windows Desktop Runtime — MIT and third-party notices — https://github.com/dotnet

Source code for SneakyFlow is supplied beside the build. Dependencies and versions are pinned in packages.lock.json. No media player or codec package is required or included: sequential downloads can be opened with the user's own player.
